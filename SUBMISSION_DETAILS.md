## Project description
MediScan AI is a student project prototype that extracts text from PDF, TXT, and supported image reports and helps users understand medical-report terminology in plain language. It uses Python and Streamlit, PDF text extraction, optional OCR, and optional Google Gemini integration.

## Important limitation
This application provides educational information only. It is not a medical device, does not diagnose, and must not be used to make treatment or medication decisions. Users should discuss reports with a qualified healthcare professional.
